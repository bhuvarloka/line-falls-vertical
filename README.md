# Heap

![screenshot](screeshot.png)

A sentence falls from the sky, one letter at a time, and piles up on the floor.

The text starts as a vertical column above the canvas. Gravity pulls it down. Letters land, tumble, and lean against each other until the whole sentence has collected itself into a small mountain of typography. Once everything has stopped moving, it stays put.

It's a quiet piece about reading something the long way around — the words are still there, you can almost find them, but they've given up on lines.

## Run it

```
pnpm install
pnpm dev
```

Open the URL it prints.

## Use it

- **Space** — pause / play
- **R** — reset and drop again

## Make it your own

Edit [src/text.txt](src/text.txt) to change the sentence.

Edit [src/config.js](src/config.js) to change how it falls. The comments next to each value tell you which direction does what — heavier, bouncier, looser, stricter.
